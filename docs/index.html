What this project actually found

Peeking is the default failure, so the test accounts for it

Fixed-horizon tests are invalid the moment somebody looks early. mSPRT keeps the error rate honest under continuous monitoring, which is how experiments are actually watched.

A sample ratio mismatch invalidates the readout entirely

If assignment is broken, every downstream number is meaningless. The SRM gate fails the experiment rather than reporting a lift computed from a broken split.

CUPED buys power without buying bias

Using pre-period data to cut variance is close to free, and the implementation is checked against the uncorrected estimate so the reduction cannot come from a changed estimand.

Interference breaks the unit of analysis

When one user's treatment affects another's outcome, per-user randomisation is already wrong. The platform models network and marketplace interference instead of assuming independence.
